## 📂 Fitxers per la pràctica

En aquest projecte trobareu l'estructura i fitxers necessaris per començar amb la pràctica.

El directori 📂 `bun-app/app` conté els fitxers del servidor web `Bun`. Aquest directori 🖐 NO s'ha de modificar. Tampoc es poden modificar els fitxers del directori 📂 `db-init`.

👉 Cal completar els fitxers de 📁 `reverse-proxy` (`Dockerfile` i `Caddyfile`) per configurar el reverse proxy, el `Dockerfile` de 📁 `bun-app` i el fitxer `docker-compose.yml` en funció de cada un dels exercicis.
